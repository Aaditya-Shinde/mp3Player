# mp3Player
This is an mp3Player that has a GUI made with Tkinter. It use pygame to play the music. The music is played from the songs folder and there can be multiple folders within songs if you want. There are 3 songs preloaded, but you can upload your own from the web. The buttons are Loop(Play the same song again until disabled) CloseAfter(The big X button, close the music player after this song finishes playing) Back(Previous song, won't go to previous song if currently at start of list because the list is shuffled after all songs have been played), Next(Play next song in list) And there is also a Volume Slider
